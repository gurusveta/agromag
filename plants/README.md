Сюда кладутся PNG-файлы с прозрачным фоном.
Имя файла = id растения из app.js.

Требования:
- Формат PNG
- Прозрачный фон
- Растение целиком в кадре
- Вид с уровня земли (не сверху)
- Оптимально 400–800 px по высоте
